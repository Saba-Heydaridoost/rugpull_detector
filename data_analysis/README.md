# data_analysis/

This folder turns the collected data in `dataset/` into model-ready artifacts. It also holds the
descriptive analyses used in the paper.

## Notebooks

### `EDA.ipynb`: main data-preparation notebook (chronological split)

1. **Clean the tables.** Cleans the label, node and edge tables and separates them by window
   (`q1`–`q3`).
2. **Define the token scopes.**
   * `full`: every valid token of a window.
   * `panel`: the 704 tokens that are valid in all three windows.
3. **Run the descriptive EDA.**
   * Labels, edge presence, token-level features and missingness.
   * Graph-summary features.
   * Gephi export of example transfer graphs.
4. **Check leakage and validity.** Verifies label construction and checks the
   predictor/outcome boundary.
5. **Split chronologically.** Splits by token creation time into 70 / 15 / 15 % train / validation
   / test, with an embargo of 9 / 8 / 7 tokens between partitions.
6. **Build the missingness cohorts.**
   * Cohorts: `original`, `drop_3_or_more_missing`, `complete_case`.
   * Variants: `no_mask` / `with_mask`. Imputation statistics are fitted on the training
     partition only.
7. **Compute training-only feature importance.**

Outputs are written to `artifacts/`. Copy `artifacts/final/` to `trainer/artifacts/final/` before
training.

### `EDA_stratified.ipynb`

The same pipeline with a stratified random split in place of the chronological one. It writes to
`artifacts_stratified/`. The paper uses it only to show that a random split overstates
performance. The trainer uses these artifacts when `RUGPULL_SPLIT=stratified`.

### `EDA_multivariate.ipynb`

The multivariate EDA. It covers:

* feature–label association, redundancy and missingness as a signal;
* PCA, t-SNE and UMAP projections;
* separability.

Section 7.7 projects the validation and test tokens of the chronological split onto a UMAP fitted
on the training tokens. That projection, with the transfer *k*NN AUC, is the UMAP figure of the
paper's split-gap appendix
(`artifacts_stratified/figures/multivariate_eda/07_chronological_split_q*.png`).

## Scripts

| Script | What it does | Output |
|--------|--------------|--------|
| `analyze_graphs.py` | Per-token structural metrics of the transfer graphs: nodes, edges, density, degree, reciprocity, centralities, timing. Reads `data/q*/edges_with_split.parquet` and `model_graph_features_with_split.parquet`. | `output/graph_metrics_per_token.csv`, `output/summary_by_q*.csv` |
| `compare_graphs.py` | Rug-pull vs non-rug graphs on the **training partition only**: Mann–Whitney U, rank-biserial *r*, and Benjamini–Hochberg FDR (the paper's structural-differences table). | `output/statistical_comparison.csv`, `output/plots/*.png` |
